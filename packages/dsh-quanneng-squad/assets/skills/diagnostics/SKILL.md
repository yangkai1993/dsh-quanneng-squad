# diagnostics · 症状路由诊断

> 渐进披露：本页只放「是什么 / 何时用 / 一条命令」；细节见 references 列出的真源文件。

## 是什么

症状路由诊断——属于全能编程小队插件的日常技能。

## 何时用

当出现故障而用户描述的是症状而非原因时使用。

## 一条命令

```bash
node scripts/squadctl.mjs obs:diagnostics
```
