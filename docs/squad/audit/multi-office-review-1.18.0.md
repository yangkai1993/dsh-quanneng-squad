# S6 多署会审 · 流程规程（1.18.0 · 2026-11-23）

> 〔依据〕edict「朝堂议政」多角色并行辩论机制 + 本项目 AGENTS §1 目录所有权（并行互斥）。
> 〔定位〕S6 监察抽巡的强化形态：重大变更（契约级/门禁级/发布级）由三署并行独立复核，取代单署串行抽巡。

## 会审触发条件（满足其一）

1. 涉及 docs/arch/api-contract.md 或宪法/门禁语义的变更；
2. 一次迭代内有 ≥3 张门红记录（supervise 报告）；
3. 发布级变更（CHANGELOG MINOR/MAJOR + install 同步）。

## 三署分工（并行独立，互不看对方结论）

| 署 | 席位 | 复核面 | 产物 |
| --- | --- | --- | --- |
| 监察 | 御史大夫 | 独立复核（不信自报，逐项对代码/实测） | docs/squad/audit/<主题>-御史.md |
| 科抄 | 给事中 | 门禁语义与 G-REFLOW 一致性、封驳意见 | docs/squad/gates/G-S< n>-给事中.md |
| 度量 | 考功郎中 | 度量口径与 L4 判据影响 | docs/squad/metrics/<迭代>-会审.md |

## 汇总规则

- 三署结论独立落盘后由总指挥汇总裁决；分歧记入 governance/decisions/ledger.md；
- 任一署给出「高危未整改」→ 本迭代不得收口（回 S4 fix loop）；
- 三署全部「符合/通过」且 L4 hard-green → S6 出门。
