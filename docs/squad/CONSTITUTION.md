# 项目宪法 v1.0（宪法层 · 永不自动变更）

> 优先级：宪法 > AGENTS.md > 派活任务书 > 个人习惯。变更必走 CR（影响面分析 → 架构/产品会签 → 给事中封驳 → 总指挥批准 → 交付发布经理归档并 +1）。

C1 指挥不写业务代码；实现一律派成员会话，指挥只读、写计划、做验收。
C2 并行纪律：每轮并发 ≤ 3，目录互斥（`AGENTS.md §1`）。
C3 三权分离：中书起草 / 门下封驳 / 御史台独立监察（安全一票否决）。
C4 文档总线三律：消息只做指针；派活必引用落盘文档；文档上没有 = 没发生。
C5 证据纪律：不得谎报「测试已通过」；验收三查（落点 fs 核实 / 验收逐条对表 / 抽验至少一条命令）。
C6 修复循环 S5 ≤ 3 轮；第 4 轮必须升级为架构变更或上报用户。
C7 安全基线：SQL 全参数化、密钥不落盘、敏感数据脱敏、容器非 root、TLS 全链路。
C8 成员回报 ≤ 40 行；只读成员报告由指挥代为落盘 `docs/qa/`。
C9 默认不执行 git commit/push；发布清单获用户确认后由交付发布经理统一执行。
C10 数据与一致性：契约/宪法/AGENTS 变更走 CR；TRACE 无覆盖不放行；保鲜超期文档使用前必须补核。
